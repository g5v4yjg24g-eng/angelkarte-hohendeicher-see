# Angelkarte Hohendeicher See

Eigenständige Angel-App (PWA) für den Hohendeicher See (Oortkatensee) in Hamburg.
Klon der Angelkarte De Witt See mit eigenem Gewässer, Hamburger Fischereirecht und getrenntem Datenspeicher.

- Daten liegen nur lokal im Browser (IndexedDB `angelkarte-hohendeicher-see`), getrennt von der De-Witt-App.
- Rechtsangaben sind teils als „ungeklärt“ markiert – maßgeblich sind der amtliche Text und die Gewässerordnung.
